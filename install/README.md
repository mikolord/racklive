# Rack Live на роутере: Keenetic / Netcraze и OpenWrt

Rack Live — обычная программа на Python без зависимостей, поэтому её можно поставить прямо на роутер. Установщик делает всё сам: ставит Python, скачивает Rack Live, оформляет его как службу (запускается вместе с роутером и сам перезапускается при сбое).

> **Сначала подумайте, нужно ли это.** Если Rack Live стоит на самом роутере и роутер зависнет, то пропадёт и мониторинг — как раз тогда, когда он нужен больше всего. Лучше всего Rack Live работает на NAS, мини-ПК или Raspberry Pi (см. «Быстрый старт» в основном README). Роутер подойдёт, если другого постоянно включённого устройства нет.

## Что понадобится

| | Keenetic / Netcraze | OpenWrt |
|---|---|---|
| Как ставится | через **Entware** (магазин пакетов на флешке) | напрямую (apk или opkg) |
| Память (ОЗУ) | от 256 МБ, лучше 512 МБ и больше | от 128 МБ (свободно не меньше 30 МБ) |
| Свободное место | от 120 МБ на флешке Entware | от 40 МБ во флеш-памяти |
| Флешка | **обязательна** (для Entware) | очень желательна для данных |
| Процессор | любой aarch64 / mips | любой, но слабые (mips) работают медленнее |

Данные Rack Live (настройки устройств, история, журнал) записываются часто. Встроенная флеш-память роутера от этого изнашивается — поэтому данные лучше держать на USB-флешке.

## Keenetic / Netcraze

### 1. Установите Entware (один раз)

Если Entware уже стоит (в веб-интерфейсе роутера есть компонент «Пакеты OPKG» и подключён накопитель), переходите к шагу 2. Если нет — [официальная инструкция Keenetic](https://help.keenetic.com/hc/ru/articles/360021214160): подключите флешку, включите компонент «Пакеты OPKG» и установите Entware на накопитель.

### 2. Подключитесь к Entware по SSH

```bash
ssh root@192.168.1.1 -p 222
```
Адрес — адрес вашего роутера. Пароль по умолчанию — `keenetic` (смените его командой `passwd`). Порт 222 — это Entware, а не сам роутер.

### 3. Запустите установщик

```bash
curl -fsSL https://raw.githubusercontent.com/mikolord/racklive/main/install/keenetic-entware.sh | sh
```
Установка занимает несколько минут. В конце скрипт покажет адрес панели, например `http://192.168.1.1:8080`. Откройте его в браузере и задайте пароль администратора.

**Если GitHub с роутера недоступен** — способ «без интернета на роутере»:
1. На компьютере скачайте [архив](https://github.com/mikolord/racklive/archive/refs/heads/main.tar.gz) (`racklive-main.tar.gz`) и сам [скрипт](https://raw.githubusercontent.com/mikolord/racklive/main/install/keenetic-entware.sh).
2. Передайте файлы на роутер (работает без scp и sftp):
   ```bash
   ssh root@192.168.1.1 -p 222 "cat > /opt/tmp/racklive.tar.gz" < racklive-main.tar.gz
   ssh root@192.168.1.1 -p 222 "cat > /opt/tmp/install.sh" < keenetic-entware.sh
   ```
3. Запустите установку из файла:
   ```bash
   ssh root@192.168.1.1 -p 222 "RL_SRC=/opt/tmp/racklive.tar.gz sh /opt/tmp/install.sh"
   ```
   (пакеты для Python роутер всё равно скачивает из репозитория Entware — для этого интернет на роутере нужен.)

### Управление
```bash
/opt/etc/init.d/S98racklive status      # работает ли
/opt/etc/init.d/S98racklive restart     # перезапуск (также start / stop)
tail -n 50 /opt/var/log/racklive.log    # журнал программы
```
Служба запускается сама вместе с Entware.

### Обновление и удаление
```bash
curl -fsSL https://raw.githubusercontent.com/mikolord/racklive/main/install/keenetic-entware.sh | sh -s update
```
Ваши настройки лежат в `/opt/var/racklive` и при обновлении не трогаются. Чтобы удалить: `sh keenetic-entware.sh uninstall` (данные останутся; `RL_PURGE=1` — удалить и их).

### Особенности на Keenetic
- В Entware нет `sshpass` и `paramiko`, но это не мешает: вход на устройства по **SSH с паролем** Rack Live выполняет средствами самого `ssh` (OpenSSH 8.4+, в Entware — 10.x). Серверы и VPS, OpenWrt, Synology по SSH, плагины работают так же, как на NAS. Вход по SSH-ключу тоже поддерживается.
- Всё остальное тоже работает: Keenetic, TP-Link, SNMP, Home Assistant, Synology (API), ping/HTTP, агент, Frank, карта, план, уведомления.
- Speedtest от Ookla на роутере не ставится: замер скорости интернета идёт через Cloudflare. Для iperf3 установите пакет: `opkg install iperf3`.
- Свой порт: `RL_PORT=8081 sh keenetic-entware.sh`. Порты 80 и 443 заняты самим роутером.

## OpenWrt

### 1. Подключитесь к роутеру по SSH
```bash
ssh root@192.168.1.1
```

### 2. (Рекомендуется) Подключите USB-флешку для данных
Вставьте флешку и убедитесь, что она смонтирована (`df -h` покажет `/mnt/sda1`). Если нет — установите поддержку USB: `apk add kmod-usb-storage block-mount` (или `opkg install …`) и смонтируйте накопитель в LuCI: **Система → Монтирование**. Без флешки установщик положит данные в `/root/racklive-data` — на флеш-память роутера.

### 3. Запустите установщик
```bash
wget -O /tmp/racklive-install.sh https://raw.githubusercontent.com/mikolord/racklive/main/install/openwrt.sh
sh /tmp/racklive-install.sh
```
Если флешка подключена, установщик сам выберет её (`/mnt/…/racklive`). Указать место вручную:
```bash
RL_DATA=/mnt/sda1/racklive sh /tmp/racklive-install.sh
```
Скрипт установит `python3-light` и нужные модули (если их не хватит, поставит полный `python3`), скачает Rack Live, создаст службу и запустит её. В конце он покажет адрес панели, например `http://192.168.1.1:8080`.

**Если GitHub с роутера недоступен:**
```bash
# на компьютере: скачать racklive-main.tar.gz и openwrt.sh, затем
ssh root@192.168.1.1 "cat > /tmp/racklive.tar.gz" < racklive-main.tar.gz
ssh root@192.168.1.1 "cat > /tmp/racklive-install.sh" < openwrt.sh
ssh root@192.168.1.1 "RL_SRC=/tmp/racklive.tar.gz sh /tmp/racklive-install.sh"
```
(пакеты Python роутер скачивает из репозитория OpenWrt — интернет на роутере для этого нужен.)

### Управление
```bash
/etc/init.d/racklive status       # работает ли
/etc/init.d/racklive restart      # перезапуск (также start / stop)
logread -e racklive | tail -n 50  # журнал программы
```
Служба запускается вместе с роутером и сама поднимается после сбоя.

### Обновление и удаление
```bash
sh /tmp/racklive-install.sh update      # скачать новую версию (данные остаются)
sh /tmp/racklive-install.sh uninstall   # удалить (RL_PURGE=1 — вместе с данными)
```

### Замечания по OpenWrt
- Если на роутере уже работает captive-портал (OpenNDS и т. п.), Rack Live ему не мешает: он слушает свой порт и ничего не меняет в настройках сети.
- Из интернета (WAN) порт закрыт файрволом OpenWrt по умолчанию — так и оставьте. Для доступа извне используйте VPN.
- Лёгкие роутеры (128 МБ ОЗУ, mips) тянут Rack Live только для небольшой сети: интерфейс отвечает чуть медленнее, чем на NAS.

## Версии и обновления: как всё держится в согласии

Rack Live — **один и тот же код** на NAS, на Keenetic и на OpenWrt. Отличаются только упаковка и запуск: на NAS это Docker, на роутерах — служба из установщика. Отдельных «роутерных» веток нет, поэтому версии не расходятся: новая версия выходит один раз и подходит всем.

Рекомендуемый порядок обновления:
1. Новую версию сначала запускают и проверяют на основном устройстве (обычно NAS).
2. Когда всё в порядке, она выкладывается на GitHub (по желанию — с меткой версии, например `v2.6.0`).
3. Роутеры обновляются одной командой: `sh keenetic-entware.sh update` / `sh openwrt.sh update`. Данные и настройки не затрагиваются.

Чтобы роутер брал только проверенную версию, а не самую свежую из ветки `main`, закрепите версию меткой: `RL_REF=v2.6.0 sh openwrt.sh update`.

Посмотреть, какая версия стоит: Настройки → «О программе» (или `GET /api/state` → `version`).

## Общие вопросы

**Как открыть панель с телефона?** Тот же адрес, что и с компьютера. Установка как приложения на экран «Домой» — Настройки → «Приложения».

**Можно ли открывать панель из интернета?** Не открывайте порт Rack Live наружу напрямую. Используйте VPN (WireGuard на роутере) или Telegram-мини-приложение.

**Как поменять порт?** Перед командой установки: `RL_PORT=8081 sh …`. Затем перезапустите службу.

**Где хранится пароль администратора?** В файле данных `config.json` в папке данных (в виде хэша, не открытым текстом). Забыли пароль — остановите службу, удалите из `config.json` блок `auth` (и блок `mfa`, если был включён второй фактор) и запустите снова: Rack Live попросит задать новый пароль.
