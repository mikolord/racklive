# Локальные плагины

Локальный плагин — ваш собственный код, который работает **внутри Rack Live** и меняет его: свои страницы и команды сервера, фоновые задачи, скрипты в интерфейсе.
Это не то же самое, что плагины сообщества (только скрипты для устройств) и контейнерные приложения (отдельный контейнер). У локального плагина **нет песочницы**:
он выполняется в процессе Rack Live с теми же правами. Поэтому защита — в порядке установки.

## Правила
- Загружает только администратор, вручную (`Инструменты → Локальные плагины → Выбрать .zip`). В каталог и на GitHub такие плагины не попадают.
- После загрузки плагин **выключен**. Включение — отдельный шаг: Rack Live показывает файлы и их отпечаток, вы читаете код и подтверждаете.
- Изменился хоть один файл — плагин выключается до нового подтверждения.
- Плагин упал при запуске — он выключается сам. Если Rack Live вообще не поднялся из-за плагина, при следующем запуске плагин выключается (файл-маркер).
- Аварийный выключатель: создайте пустой файл `OFF` в `data/local-plugins/` (или переменная `RL_NO_LOCAL_PLUGINS=1`) — Rack Live запустится без плагинов.
- «Выключить» останавливает маршруты и фоновые задачи. Всё, что плагин успел поменять в памяти (например, подменил функцию), исчезнет после перезапуска.

## Формат (`local_api` = 1)
Архив `.zip`:
```
plugin.json   {"local_api": 1, "id": "my-plugin", "title": "…", "description": "…", "version": "1.0.0", "author": "…"}
main.py       def register(api): …          (необязательно)
ui.js         скрипт, который грузится в страницу Rack Live для администратора   (необязательно)
panel.html    своя страница, открывается из карточки плагина                      (необязательно)
```
Нужен хотя бы один из трёх файлов. Разрешены расширения `.json .py .js .html .css .md .txt .svg .png`, до 1 МБ в архиве.

## API для `main.py`
`register(api)` вызывается один раз при включении.

| | |
|---|---|
| `api.route(method, path, fn)` | маршрут `/api/x/<id>/<path>`; `fn(req)` возвращает `dict` (JSON), `(код, dict)` или `(код, bytes, content_type)`. Только для вошедшего администратора |
| `api.every(seconds, fn)` | фоновая задача (не чаще раза в 5 секунд); остановится, когда плагин выключат |
| `api.event(level, text)` | запись в журнал событий (`info` / `warning` / `error`) |
| `api.log(text)` | запись в журнал плагина (виден в его карточке) |
| `api.devices()` | копия списка устройств, пароли, токены и ключи заменены на `***` |
| `api.data_dir` | собственная папка плагина для данных |
| `api.version` | версия Rack Live |

`req`: `req.method`, `req.path`, `req.query` (словарь), `req.body` (байты), `req.json()`.

Плагин на Python — это обычный Python: он может импортировать что угодно. Всё, что выходит за рамки API выше, — на вашей ответственности.

## Пример
```python
# main.py
def register(api):
    api.route('GET', 'hello', lambda req: {'hello': 'мир', 'devices': len(api.devices())})
    api.every(3600, lambda: api.log('прошёл час'))
```
Ответ: `GET /api/x/my-plugin/hello`. Страница `panel.html` может обращаться к нему обычным `fetch('/api/x/my-plugin/hello')`.
