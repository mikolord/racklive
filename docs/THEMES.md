# Своё оформление Rack Live

Rack Live можно перекрасить и переименовать целиком: цвета и скругления, шрифты, **каждую иконку**, иконки приложений (Rack Live, Frank, «Тест скорости»), значок для экрана «Домой»,
цвета типов устройств, тексты (вкладки, окно входа, имя Frank, **все шаги приветственного обучения**), а через CSS — вид любого блока, вплоть до фоновых картинок и шрифтов.

Оформление — это **zip-архив с данными** (JSON, CSS, картинки). Программ внутри нет и быть не может: Rack Live ничего не запускает из архива.

## Как добавить

1. Настройки → **Оформление** → **«Добавить своё»** → выберите `.zip`.
2. Rack Live проверит архив. **Ошибки** — оформление не установится, будет написано, что исправить. **Замечания** — установится, часть настроек может не подействовать.
3. Выберите оформление в списке «Стиль интерфейса». Выбор запоминается на устройстве: на телефоне и компьютере могут быть разные.

Если оформление стало нечитаемым — откройте адрес панели с добавкой `?skin=classic` (например `http://192.168.1.3:9998/?skin=classic`): вернётся стандартное.

## Как сделать своё (в том числе с помощью нейросети)

1. В «Настройки → Оформление» нажмите **«Скачать шаблон (.zip)»** — это работающий пример, который можно править.
2. Нажмите **«Инструкция для нейросети (.txt)»** (тот же файл лежит в репозитории: [`theme-guide.txt`](theme-guide.txt)).
3. Отдайте нейросети этот файл и опишите, что хотите («тёмно-синее оформление в морском стиле, свои иконки, Frank зовут Нептун»). Она соберёт `theme.json`, `theme.css` и картинки.
4. Упакуйте в `.zip` (файл `theme.json` в корне архива) и загрузите. Если Rack Live вернул ошибки — отдайте их нейросети, она исправит.

Готовый образец: [`themes/ocean-night.zip`](themes/ocean-night.zip) («Океанская ночь»: цвета обеих тем, свои иконки, переименованные вкладки, Frank = «Нептун», свои тексты обучения, значки приложений и PNG для «Домой»).
Его исходные файлы — в [`themes/ocean-night/`](themes/ocean-night/).

## Что внутри архива

```
theme.json       обязательный: id, name, version, api, base, tokens, strings, icons, kindColors, appIcons, pwa
theme.css        необязательный: свои правила, каждый селектор начинается с html[data-theme-id="ВАШ-ID"]
assets/…         картинки (svg, png, jpg, webp) и шрифты (woff2)
```

Полное описание всех полей, список переменных, стабильных классов, ключей текстов, имён иконок и чек-лист — в [`theme-guide.txt`](theme-guide.txt).

## Чтобы обновления Rack Live ничего не ломали

* У «контракта» оформления есть номер — **`api`** (сейчас **1**). В `theme.json` указывается, для какого номера сделана тема.
* Rack Live **проверяет оформление при загрузке и после каждого обновления**: подходит ли оно к установленной версии. Если нет — оформление **отключается само**, интерфейс возвращается к стандартному,
  а причина показывается в разделе «Оформление» и в «Событиях».
* Мы не удаляем и не переименовываем переменные, стабильные классы, ключи текстов и иконки без повышения номера `api`. Всё, чего нет в списках, — ненадёжно, и Rack Live предупредит об этом при загрузке.
* Неизвестные ключи (например, текст, которого в новой версии уже нет) — только замечание: они игнорируются, тема продолжает работать.

## Безопасность

* Принимаются только данные: JSON, CSS, картинки, шрифты woff2. Любые другие файлы отклоняются.
* CSS обязан быть «заперт» внутри своей темы (`html[data-theme-id="…"]`): правило без такого начала — ошибка. Запрещены `@import`, внешние ссылки, `url()` вне папки `assets/`, `expression()`, `javascript:`.
* SVG проверяются на скрипты, обработчики событий, `foreignObject` и внешние ссылки. Файлы оформления отдаются с политикой `sandbox`: даже открытый напрямую, скрипт из них не выполнится.
* Загружать оформление может только администратор. Лимиты: архив 8 МБ, файл 3 МБ, `theme.css` 400 КБ.

## Иконка приложения на экране «Домой»

Внутри Rack Live иконки приложений меняются сразу. А уже установленный значок на телефоне сам не обновится (так устроен iOS): удалите его и добавьте заново после выбора оформления.
