# Контейнерные приложения для Rack Live (формат app_api 1)

Приложение — это **описание** (`app.json`), а не код. Rack Live по нему собирает файл docker compose, показывает администратору, что именно будет запущено и какие у него права,
и только после подтверждения запускает на выбранном сервере (SSH) или NAS Synology. Раздел: Инструменты → Приложения. Внутрь самого Rack Live приложение не попадает.

Проверить описание можно в Rack Live: `POST /api/capps/check` с `{"app": "<текст app.json>"}` (нужен вход администратора) — вернёт ошибки, предупреждения,
уровень риска, разрешения словами и готовый compose-файл. Тот же код проверяет приложения при публикации в каталог.

## Минимальный пример

```json
{
  "app_api": 1,
  "id": "uptime-kuma",
  "title": "Uptime Kuma",
  "description": "Мониторинг сайтов и служб с уведомлениями",
  "version": "1.23.16",
  "home": "https://github.com/louislam/uptime-kuma",
  "license": "MIT",
  "author": "Louis Lam",
  "targets": ["ssh", "synology"],
  "fields": [{"id": "tz", "label": "Часовой пояс", "type": "text", "default": "Europe/Moscow"}],
  "services": {
    "app": {
      "image": "louislam/uptime-kuma@sha256:<64 символа хеша>",
      "memory": "512m",
      "cpus": 1,
      "ports": [{"container": 3001, "host": 3001, "label": "Веб-интерфейс", "web": true}],
      "volumes": [{"name": "data", "path": "/app/data"}],
      "env": {"TZ": "${RL_P_TZ}"}
    }
  },
  "ui": {"mode": "link", "service": "app", "port": 3001, "path": "/", "title": "Открыть Uptime Kuma"}
}
```

Хеш образа: `docker pull имя:тег`, затем `docker inspect --format '{{index .RepoDigests 0}}' имя:тег`.

## Как открывается приложение (`ui.mode`)

| режим | что происходит | когда выбирать |
|---|---|---|
| `link` (по умолчанию) | кнопка «Открыть» открывает адрес приложения в новой вкладке | подходит всегда, особенно если у приложения свой интерфейс |
| `embed` | интерфейс показывается внутри Rack Live | только если приложение разрешает показ во вкладке (многие запрещают) |
| `none` | интерфейса нет, Rack Live показывает состояние и адрес для подключения | фоновые службы: DNS, прокси, мониторинг |

`ui.port` — это порт **на устройстве** (`host`) у порта с `"web": true`. `ui.scheme` — `http` (по умолчанию) или `https` (например, у UniFi интерфейс на https://адрес:8443).

## Правила (нарушение — приложение не принимается)

- Образ закреплён по хешу: `имя@sha256:…`. Реестры: docker.io, ghcr.io, lscr.io, quay.io, mcr.microsoft.com.
- Обязателен предел памяти (`memory`, от 32m до 4g): приложение не должно съесть всё устройство. Процессор: `cpus` до 4.
- Запрещено: privileged, host-сеть, общие процессы, `docker.sock`, системные папки (`/proc`, `/sys`, `/dev`, `/etc` …), `security_opt`, `sysctls`. Все права снимаются (`cap_drop: ALL`).
- Можно просить только: права `NET_BIND_SERVICE`, `CHOWN`, `SETUID`, `SETGID`, `DAC_OVERRIDE`, `FOWNER`, `NET_RAW` (ping), `NET_ADMIN`; устройства `/dev/net/tun`, `/dev/dri`. Каждое повышает уровень риска и показывается словами.
- Порты хоста любые (1–65535), но порт ниже 1024 (DNS 53, веб 80/443) поднимает риск до среднего: если порт занят другой службой, приложение не запустится. Rack Live **не открывает порты в интернет**.
- Тома: только именованные (`"name"`) — они принадлежат приложению. Папку устройства можно подключить только через поле `type: "path"`, которую администратор выберет при установке, по умолчанию только для чтения.
- Никаких лишних полей: неизвестное поле отклоняет приложение целиком.
- Значения настроек подставляются как `${RL_P_ПОЛЕ}`; знак `$` в другом виде запрещён.

## Уровень риска

- **низкий** — только свои порты и тома;
- **средний** — читает папку устройства, `NET_RAW`, `/dev/dri`, много портов, память более 2 ГБ;
- **высокий** — пишет в папку устройства, `NET_ADMIN`, `/dev/net/tun`.

## Открыть приложение из интернета

Rack Live этого не делает. Нужно зайти на роутер и пробросить порт приложения на адрес устройства, где оно запущено.
Это решение владельца сети: приложение из интернета видно всем, поэтому защитите его паролем и не открывайте то, что не рассчитано на интернет.

## Готовые примеры и чужие программы

В Rack Live уже лежат описания **UniFi Network Application** (с MongoDB, два контейнера) и **Uptime Kuma**: их можно добавить в Инструменты → Приложения одной кнопкой.
Так можно описать любую известную программу, у которой есть готовый образ Docker: автору программы ничего менять не нужно.
Собирать образ из исходников на устройстве (git-репозиторий с Dockerfile) пока нельзя: нужен готовый образ в одном из разрешённых реестров.
