ИНСТРУКЦИЯ: КАК СДЕЛАТЬ СВОЁ ОФОРМЛЕНИЕ ДЛЯ RACK LIVE
Версия контракта оформления (api): 1. Rack Live 2.5.0.

Это файл для человека и для нейросети. Если вы читаете его как нейросеть: ваша задача — по описанию пользователя создать ZIP-архив оформления,
строго соблюдая правила ниже. Ничего вне этих правил не придумывайте — архив с нарушениями Rack Live не примет и объяснит, что не так.

1. ЧТО ТАКОЕ ОФОРМЛЕНИЕ
Это набор ФАЙЛОВ-ДАННЫХ (JSON, CSS, картинки). Никакого JavaScript, HTML-страниц и программ — они не запускаются и не принимаются.
Оформление может поменять: цвета и скругления, шрифт, любую иконку интерфейса, иконки приложений (Rack Live, Frank, Тест скорости),
иконку для экрана «Домой» (PWA) и значок вкладки, цвета типов устройств, тексты (вкладки, окно входа, имя Frank, ВСЕ шаги приветственного обучения),
а через theme.css — внешний вид любого блока (карточки, кнопки, плитки, шапка, док, окна, Frank, обучение), включая фоновые картинки и шрифты woff2.

2. СТРУКТУРА АРХИВА (.zip)
   theme.json        — обязательный, описание и настройки (см. раздел 3)
   theme.css         — необязательный, свои правила CSS (см. раздел 5)
   assets/…          — картинки (svg, png, jpg, webp) и шрифты (woff2), на которые ссылаются файлы выше
Файл theme.json должен лежать в корне архива (допускается одна общая папка внутри). Разрешённые типы файлов: .css, .jpeg, .jpg, .json, .md, .png, .svg, .txt, .webp, .woff2.
Лимиты: архив до 8 МБ, не больше 200 файлов, файл до 3 МБ, theme.css до 400 КБ, картинка до 1 МБ, SVG до 300 КБ.

5. theme.css — СВОИ ПРАВИЛА
ГЛАВНОЕ ПРАВИЛО: каждый селектор начинается с  html[data-theme-id="ВАШ-ID"]  (id из theme.json). Пример:
   html[data-theme-id="ocean-night"] .card { border-radius: 28px; }
   html[data-theme-id="ocean-night"] .btn.primary, html[data-theme-id="ocean-night"] .tour-next { background: #0ea5e9; }
Так тема не может повлиять на что-то вне себя. Разрешено: обычные правила, @media, @supports, @keyframes (имя начинайте с id темы: ocean-night-имя), @font-face (только .woff2 из assets/).
ЗАПРЕЩЕНО: @import, внешние ссылки (https://…), url() кроме assets/имя и data:image, обратный слэш вне кавычек, expression(), javascript:, behavior, <script>, @charset, @page, @container.
Фон-картинка:  background-image: url(assets/bg.jpg)   (файл лежит в assets/).

8. ИКОНКИ ПРИЛОЖЕНИЙ И PWA
appIcons.rack / frank / speed — картинки (svg, png, jpg, webp), показываются в шапке, на экране входа, в настройках и в приложениях Frank и «Тест скорости».
pwa.favicon — значок вкладки (svg или png). pwa.appleTouch — PNG 180×180, pwa.icon192 — PNG 192×192, pwa.icon512 — PNG 512×512: ими пользуется iPhone/Android
при добавлении на экран «Домой». ВАЖНО: уже установленный значок на телефоне сам не меняется — нужно удалить его и добавить заново после выбора темы.
SVG: без скриптов, без внешних ссылок, без foreignObject, без атрибутов on…=.

       html[data-theme-id="ID"] .port.g { background-image: url(assets/port-up.svg); background-size: 62%; background-repeat: no-repeat; background-position: center; }
   • Подсказки (жёлтые плашки вверху вкладок): --hint-bg, --hint-line, --hint-text, --hint-ico, --hint-ico-bg, --hint-close-bg, --hint-close-text, --hint-radius; иконка лампочки — icons "bulb"; класс .hint-box.
   • Frank: глаз рисуется сам — его цвета задают --frank-sclera (белок), --frank-pupil, --frank-lid (веко), --frank-iris-0/1/2 (радужка), --frank-bg (плитка за глазом), --frank-glow (сияние в обучении),
     настроения --frank-m2-* («напряжён») и --frank-m3-* («тревога»). ИЛИ замените глаз своей картинкой: "frankAvatar": "assets/файл.svg" (svg/png/webp, квадрат). Имя — strings "frank.name"; значок приложения — appIcons.frank.

8в. ПЛИТКИ ВИДЖЕТОВ И ЗНАЧКИ «ДОМОЙ» У ВСЕХ ТРЁХ ПРИЛОЖЕНИЙ
   • Квадратная плитка виджета: фон — --tile-bg (можно градиент), маленький значок в углу — --tile-ic-bg и --tile-ic-fg; классы .wg .wg-in .wg-tile .wg-tile-ic .wg-tile-name .wg-tile-art .wg-tile-v .wg-tile-s .size-S .size-M .size-L.
     Нарисованную миниатюру (кольцо, батарейка, спидометр, столбики…) можно заменить КАРТИНКОЙ через "tileArt" либо скрыть/заменить средствами CSS; цвет плитки — "tileColors". Виджеты: rack, stats, problems, state, internet, ups, uptime, newdev, map, plan, devices, events, speed, frank, advice, shortcuts, note.
   • Значки для экрана «Домой» задаются отдельно для каждого приложения: "pwa" — Rack Live, "pwaFrank" — Frank, "pwaSpeed" — Тест скорости; у каждого favicon, appleTouch (PNG 180×180), icon192, icon512 (PNG).

8а. ПОДСКАЗКИ И ЛОВУШКИ ДЛЯ АВТОРА
   • Сначала tokens, потом css. Цвета через переменные работают везде, в том числе внутри шкафа, карты и виджетов, и переживают обновления лучше всего.
   • Всегда задавайте и dark, и light (или «all»): человек может переключить тему. Проверьте контраст текста и фона в обеих.
   • Виджеты на главной содержат вложенные .card без рамки и фона. Если вы стилите .card (тень, рамка, фон) — добавьте исключение:
       html[data-theme-id="ID"] .wg-body > .card { box-shadow: none; border: 0; background: none; }
   • Не прячьте элементы через display:none: можно скрыть кнопку, без которой нельзя пользоваться приложением. Тема не должна ломать управление.
   • Проверьте узкий экран (телефон, ширина 390 px): правила для него пишутся через @media (max-width: 760px) { html[data-theme-id="ID"] … }.
   • Имена Frank и текст приветствия заменяются только там, где есть ключ в списке строк (раздел 6); остальные подписи остаются по умолчанию.
   • Иконку на экране «Домой» меняют только при новой установке значка; в самом интерфейсе иконки приложений (appIcons) меняются сразу.
   • Меняйте контракт осторожно: если при обновлении Rack Live число api станет другим, тема будет отключена и вернётся стандартный вид — тогда обновите тему по новой инструкции.

9. КАК ЗАГРУЗИТЬ И ПРОВЕРИТЬ
Настройки → Оформление → «Добавить своё» → выберите .zip. Rack Live проверит архив и покажет ОШИБКИ (тема не установится) и ПРЕДУПРЕЖДЕНИЯ (установится).
Если после выбора темы интерфейс стал нечитаемым — откройте адрес панели с добавкой ?skin=classic (например http://адрес:порт/?skin=classic): вернётся стандартное оформление.
После каждого обновления Rack Live все темы проверяются заново; несовместимая тема отключается сама, интерфейс возвращается к стандартному, причина показывается в разделе «Оформление».

10. ПОРЯДОК РАБОТЫ ДЛЯ НЕЙРОСЕТИ
   а) уточните у пользователя идею (цвета, настроение, что менять: только цвета / ещё иконки / тексты / обучение / иконки приложений);
   б) придумайте id, name, version "1.0.0", api 1, выберите base;
   в) составьте theme.json: начните с tokens (dark и light), затем strings/icons/kindColors при необходимости;
   г) только если нужно — theme.css с селекторами html[data-theme-id="id"] …; картинки — в assets/;
   д) выдайте файлы и структуру архива; проверьте себя по чек-листу ниже.
ЧЕК-ЛИСТ: ☐ theme.json — валидный JSON без комментариев  ☐ id из допустимых символов и не зарезервирован  ☐ "api": 1  ☐ все пути (css, assets/…) существуют в архиве
   ☐ каждый селектор в theme.css начинается с html[data-theme-id="id"]  ☐ нет @import, http(s)://, обратных слэшей, url() вне assets/  ☐ в SVG нет скриптов и внешних ссылок
   ☐ для светлой и тёмной темы заданы читаемые цвета текста и фона (контраст)  ☐ ключи strings, icons, kindColors взяты из списков выше.
