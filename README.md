# Rack Live

Серверный шкаф и карта сети с живыми данными. Нарисуйте свой шкаф, добавьте устройства — Rack Live сам соберёт
порты, VLAN, PoE, клиентов, диски и состояние, построит карту соединений и покажет, где проблема.

- **Шкаф** — юниты с живой сводкой и светодиодами портов, перетаскивание в режиме редактирования.
- **Карта сети** — шкаф и кабели от его портов к камерам, точкам доступа, серверам; Wi-Fi-клиенты у своих точек; удалённые объекты через интернет. Строится автоматически, можно дорисовать свои связи.
- **Устройства** — карточки с CPU, памятью, температурой, графиками за сутки, лицевой панелью портов, клиентами, дисками, контейнерами.
- **Управление** (после входа): перезапуск PoE и порта коммутатора, перезагрузка роутера и точек, перезапуск Docker-контейнеров Synology, выключатели Home Assistant.
- **События** — когда что пропало и вернулось.
- **Удалённые объекты** — проверка по ping / порту / сайту, а для серверов за NAT — агент, который сам присылает данные.

## Установка (Docker)

```bash
git clone https://github.com/mikolord/racklive.git && cd racklive
docker compose up -d --build
```

Synology: скачайте ZIP (Code → Download ZIP), распакуйте в docker/racklive, затем Container Manager → Проект → Создать → путь к этой папке (там лежит docker-compose.yml) → Готово.
Windows / macOS: установить Docker Desktop, в папке racklive выполнить `docker compose up -d --build`.

Откройте `http://<сервер>:8080`, задайте название и пароль администратора — и добавляйте устройства.
Все данные лежат в папке `./data` (её и нужно бэкапить; в настройках есть выгрузка резервной копии).

Без Docker: нужен только Python 3.9+ — `python -m rackd` (переменные `RL_DATA`, `RL_PORT`).

## Поддерживаемые устройства

| Тип | Что собирается | Управление |
|---|---|---|
| Keenetic / Netcraze (RCI) | порты, VLAN, клиенты по сегментам, mesh-точки и их Wi-Fi-клиенты, WAN, KeenDNS | перезагрузка роутера и точек |
| TP-Link JetStream (telnet) | линк, скорость, PoE по портам, VLAN, MAC-таблица (кто на каком порту) | перезапуск PoE, перезапуск порта |
| Synology DSM | диски, тома, температура, CPU/RAM, сетевые карты, контейнеры | перезапуск контейнера |
| Home Assistant | версия, объекты, недоступные устройства, выключатели и свет | включить / выключить |
| OpenWrt (ubus) | модель, прошивка, память, интерфейсы, DHCP-клиенты | перезагрузка |
| Доступность | ping или TCP-порт, задержка | — |
| Сайт | код ответа, время, срок сертификата, наличие текста | — |
| Агент | CPU, память, диски, температура, Docker на любом Linux | — |

Новый тип устройства — это один файл в `rackd/drivers/`: класс с методом `poll()` (и при желании `action()`),
возвращающий словарь в общем формате (см. `rackd/drivers/__init__.py`).

## Безопасность

- Пароли устройств хранятся в `data/config.json` (права 600) и никогда не отдаются в браузер.
- Без входа можно включить только просмотр (Настройки → «Просмотр без пароля»); управление — только администратору.
- Для доступа из интернета ставьте Rack Live за HTTPS (reverse proxy) — cookie получит флаг Secure по `X-Forwarded-Proto`.
- Для порта-uplink коммутатора укажите «Защищённые порты», чтобы случайно не выключить связь.

## Разработка

Интерфейс — React 18 (без сборщика модулей): исходники в `web/src/*.jsx`, сборка `python build.py`
(нужен Node.js, Babel ставится в `web/node_modules` автоматически). Сервер — только стандартная библиотека Python.

## Обновление

```bash
cd racklive && git pull && docker compose up -d --build
```

Папка `data` при обновлении не трогается.
